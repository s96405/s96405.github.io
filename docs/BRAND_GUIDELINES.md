# FlowForge Brand Guidelines

## Brand Positioning

FlowForge helps enterprises simplify daily work through:

- Internal Systems
- Workflow Automation
- Data Integration
- Manufacturing Process Improvement

---

## Brand Personality

FlowForge should feel:

- Professional
- Reliable
- Mature
- Practical
- Efficient

Never feel:

- Experimental
- Flashy
- Trendy
- Startup Demo

---

## Design Direction

Inspired by:

- Linear
- Stripe
- Vercel
- Retool
- Framer

Reference only:

- Typography
- Spacing
- Product Showcase
- Information Hierarchy

Never copy:

- Layout
- Components
- UI
- Copywriting

---

## Color

Primary Accent

Electric Blue

Overall

- Dark
- High Contrast
- Low Saturation

---

## Typography

Readable.

Confident.

Professional.

Never decorative.

---

## Product Philosophy

Technology supports value.

Technology is not the headline.

Visitors should first understand:

"What business problem does FlowForge solve?"

Not:

"What technologies does it use?"

---

## Avoid

Avoid:

- Neon
- Gaming UI
- Excessive Glassmorphism
- Heavy Shadows
- Large Logo Walls
- Engineer Portfolio Style
- Dashboard Gallery

---

## Design Maturity

Prefer trust over visual impact.

Enterprise customers should feel:

"This is a real product."

Not:

"This is a design concept."
