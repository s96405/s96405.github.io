關於我

我目前是大三學生，也在工作中接觸公司內部系統的調整、測試與維護。 相比單純製作畫面，我更重視理解資料如何從使用者輸入、後端處理、 資料庫儲存，到最後產生查詢與報表。

目前透過報工系統、工程專案進度追蹤系統與 RPA 自動化工具， 累積需求理解、畫面調整、功能測試、資料查詢與錯誤排查的經驗。 開發過程中也會使用 AI 工具輔助理解程式，並逐步補強前後端與資料庫基礎。

能力與工具

Frontend

能調整表單畫面、查詢條件、資料表格與響應式版面， 持續補強 JavaScript 互動邏輯與資料顯示能力。

Backend

理解 API 路由、表單送出、資料驗證與資料庫查詢流程， 正在加強 Flask、Node.js 與 Express 的基礎。

Database

能閱讀與練習 SQL 查詢，理解資料表欄位、條件篩選、 關聯查詢與報表資料來源。

Tools

使用 GitHub 管理專案版本，並透過 VS Code、DBeaver、 Excel 與 AI 工具輔助開發、測試與排查問題。

工廠現場報工與報表查詢系統

現場報工若依賴人工紀錄與 Excel，容易造成查詢不便與資料整理耗時。 這個專案主要協助將報工流程網頁化，讓人員可以輸入製令、 良品數、不良品數，並透過系統查詢與匯出報表。

接觸內容

  • 登入與角色權限流程
  • 製令資料查詢與報工表單送出
  • 報工紀錄查詢、篩選與 Excel 匯出
  • 前端、後端 API 與 MySQL 之間的資料流
Node.js Express MySQL JavaScript

工程專案進度與工作紀錄系統

工程部門除了填寫每日工作內容，也需要追蹤專案進度、問題狀態與延期紀錄。 這個系統將工作紀錄與專案任務結合，讓資料可以被查詢、追蹤與整理成報表。

接觸內容

  • 每日工作紀錄填寫與查詢
  • 專案任務進度追蹤
  • 延期紀錄與問題追蹤
  • Flask 路由、表單處理與資料表關聯概念
Flask MySQL SQLAlchemy ERP 概念

QMS 圖面更新 RPA 自動化工具

對於需要重複操作網頁與比對資料夾檔案的流程，嘗試透過 Python 製作自動化工具， 協助減少人工重複操作，並學習如何處理流程判斷、例外狀況與環境差異。

接觸內容

  • 讀取 Excel 與本機資料夾檔案
  • 透過 Selenium / PyAutoGUI 操作網頁流程
  • 處理流程判斷、錯誤紀錄與操作穩定性
  • 學習 PyInstaller 打包與不同電腦環境相容問題
Python Selenium PyAutoGUI Automation
