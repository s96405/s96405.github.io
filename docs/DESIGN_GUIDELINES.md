# FlowForge Design Guidelines

## Layout Principles

Each section should have:

One visual focus.

Everything else supports it.

---

## Hero

Requirements:

- Strong headline
- Clear value proposition
- Clear CTA
- No overflow
- Desktop and Mobile optimized separately

---

## Services

Use:

- Split Layout
- Lists
- Numbered Sections

Avoid:

Large repetitive cards.

---

## Case Studies

Homepage's strongest proof.

Rules:

- Product Preview larger than decorations
- Every case has its own rhythm
- Mobile Preview first
- Copy below
- No horizontal scrolling

---

## About

Focus on:

- Workflow
- Problem Solving

Avoid:

Resume style.

---

## Contact

Simple.

Clear.

Single CTA.

---

## Visual Hierarchy

One Hero.

Everything else supports it.

Avoid competing emphasis.

---

## Information Density

Do not remove meaningful product information.

Keep:

- KPI
- Workflow
- Status
- Tasks

---

## Responsive Design

Desktop and Mobile are different experiences.

Never simply shrink Desktop.

Instead:

- Reorganize layouts
- Reduce information density
- Improve reading flow

---

## Mobile Design

Mobile should feel intentionally designed.

Not scaled down.

Prioritize:

- Reading speed
- Touch interaction
- Hero visibility
- Product understanding

---

## Mobile UX Checklist

Review:

Navigation

Hero

Services

Case Studies

Timeline

About

Contact

If Mobile UX is poor:

Recommend layout improvements.

Not simply smaller fonts.
