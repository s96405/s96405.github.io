關於我

我目前就讀台中科技大學資訊工程系，並在工作中參與公司內部系統的調整、 測試與維護。主要接觸的範圍包含報工流程、工程專案追蹤、資料查詢、 報表整理與 RPA 自動化工具。

在專案實作中，我關注的不只是畫面呈現，而是完整的資料流與系統流程： 從使用者輸入、前端送出資料、後端 API 處理、資料庫儲存與查詢， 到最後產生報表與操作結果。透過實際需求與系統維護經驗， 持續累積前後端整合、資料庫操作與問題排查能力。

能力與工具

Frontend

HTML、CSS、JavaScript，負責表單頁面、查詢條件、 資料表格與響應式版面調整，讓系統操作流程更清楚。

Backend

Python Flask、Node.js、Express，理解路由設計、 API 請求回應、表單處理、資料驗證與錯誤排查流程。

Database

MySQL、SQLite、SQL Server 查詢概念，處理資料查詢、 條件篩選、資料表關聯與報表資料來源整理。

Workflow & Tools

Git、GitHub、VS Code、DBeaver、Excel、RPA 與 AI 工具， 用於版本管理、資料檢查、流程測試與開發輔助。
